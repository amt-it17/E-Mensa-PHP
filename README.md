🍽️ E-Mensa – Web Development Project
📌 Project Overview
E-Mensa is a web development project created as part of my Computer Science studies at FH Aachen University of Applied Sciences.

The project started as a static website using HTML and CSS and was later extended with PHP to introduce dynamic content, form processing, and basic data management.

The goal is to develop a structured, user-friendly, and functional university cafeteria website.

💻 Technologies Used
HTML5 – Website structure
CSS3 – Layout and styling
PHP – Server-side programming
CSV and text files – Basic data storage
Git & GitHub – Version control
PhpStorm – Development environment
🚀 Features
🌐 Website Structure
Structured web pages using HTML5
Navigation between different sections
Tables, images, and hyperlinks
Website styling using CSS
🍽️ Dynamic Menu
Dynamic display of cafeteria meals using PHP
Meal information stored in PHP arrays
Display of meal prices and images
Automatic calculation of the number of available meals
📧 Newsletter Registration
Newsletter registration form
Form processing using HTTP POST
Input validation using PHP
Email address validation
Error and success messages
Registration data stored locally in a CSV file
📊 Website Statistics
Visitor counter based on HTTP GET requests
Automatic counting of available meals
Total number of newsletter registrations
Dynamic display of statistics using PHP

▶️ How to Run the Project
This project requires PHP.

Download or clone the repository.

Open the project folder in PhpStorm or another code editor.

Open a terminal in the project directory.

Start the PHP development server:

php -S localhost:8000

Open the following address in your browser:

http://localhost:8000/werbeseite.php

Note: Newsletter registrations and visitor statistics are stored in local files. These files are excluded from version control to protect user data.
